# Introduction

**WordKey** turns a site's contextual vocabulary into two things: word-search puzzles people play, and a `vocab.md` file agents load. This instance is the **WordKey Playground** — try the sample vocabulary here, or deploy your own instance so your visitors play *your* vocabulary and your agents load *your* words. See the deploy guide in the project README.

This application has three main sections: the **Maker** for creating puzzles, the **Player** for playing them, and **Settings** for managing the app. Use the main sidebar on the left to navigate between these core areas. This documentation provides a guide on how to use each section effectively.
